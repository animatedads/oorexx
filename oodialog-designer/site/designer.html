Strings each language is a `::RESOURCE strings.` in the program, `key = text`
    

  
The texts are written into the program as they are.  To translate them, give the language they are in:
     

  

    Add a language  
    New event string   
  

  

  
Edit a text in place.  An empty cell in a translation uses the base language's text.  In event code: `self~nls("key", value1, value2)`; %1, %2 in the text take the values.  ⇩ gives a translator the language as a plain `key = text` file; ⇧ reads it back.
