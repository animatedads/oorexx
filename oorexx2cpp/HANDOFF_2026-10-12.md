## Open items (in priority order)

1. **json.cls native is slower than interpreted json.cls.** The out-of-memory on a 110 KB document is fixed (native
   `[]`, VERIFY with options, cached String ISA; message receivers read by reference). Now, 2000 records (110 KB):
   native toJSON 4.3 s / fromJSON 4.6 s (machine loaded) vs interpreter 0.59 s / 1.25 s; 200 records: 0.21 s / 0.21 s vs
   0.04 s / 0.07 s. The growth is worse than linear, so something still copies the whole JSON string per step: first
   suspect `parse value jsonString with =(jsonPos) char +1` (the PARSE source is read with RX_VGET, a full copy).
   Repro (`tools/session_2026-10-12/jb.rex` + `::requires 'jsonlib' library`):
   ```
   RX2CPP_STRING_FALLBACK_STATS=1 LD_LIBRARY_PATH=<jsonlib dir>:$OR/lib rexx jbn.rex
   ```
2. Sockets: not tested yet (socket.cls / streamsocket.cls / rxsock). Next after item 1.
3. Maths and compress: native slower than the interpreter on object-heavy / string-heavy paths. Profile with
   callgrind (see "Profiling" below); costs are spread over boundary crossings, not one hotspot.
4. `parse` templates evaluate `(expr)` patterns before parsing starts (ooRexx evaluates them when reached, after
   earlier targets are set).
5. `.CONTEXT` answers only `PACKAGE`; `DROP` is not compiled; `RANDOM`/`LINEIN` need the interpreter in plain builds;
   `FORMAT` exponent arguments not implemented.
6. Classes using REPLY/GUARD run in the hosted interpreter (by design for now).
7. ChatGPT's `native/test_object_boundaries.sh` (d7db8ee) passes with g++ on this main; Clang not run. Open risk it
   raised: `rxobj::release()` drops global refs only while a thread-local interpreter context is active; needs an
   ownership/GC test (objects released from UNINIT or another thread).

## What changed this session (high level)

- Language: shared stem objects; `select case`; `do ... to/by/for/while/until`, `do counter c x over`, bare `do` groups;
  IF/WHEN condition lists (`if a, b then`); THEN on the next line; strict compares `<< >> <<= >>= \< \> \<< \>>`;
  `a[i,j]`, `a[i] += x`, `.local['x'][k] = v`; keyword words as variables (`guard = 10`); abutted sub-keywords;
  `use arg x = expr`, `use strict arg` with expression defaults or no names; duplicate labels / label fall-through;
  PARSE `=(expr)` `+(expr)` `-(expr)` `(expr)`; relative positions after a string pattern; RAISE ... ADDITIONAL.
- Native lane: package prolog code; user UNINIT and UNKNOWN; empty subclasses; quoted class names (`::class "JSON"`);
  `::attribute x get` with a body; interpreter mixins (COMPARABLE ...); FORWARD TO (obj) / MESSAGE (expr) /
  ARGUMENTS / ARRAY / CLASS (SUPER) incl. class side; package routines take/return objects; CALL of package routines;
  rexxutil and other interpreter-resolved routines (stem arguments copied back); stream BIFs share one stream per name;
  `.LOCAL`/`.ENVIRONMENT`/`.REXXINFO`/package-local symbols; `.CONTEXT~PACKAGE`; SYNTAX conditions keep their number
  and substitutions across the boundary; String subclasses (JsonString) stay objects.
- Runtime: variable slots; int64 decimal fast paths; native DATATYPE/MAX/MIN/ABS/POS/LASTPOS/C2D/D2C/X2D/D2X and the
  common string BIFs; bignum parsing/digit counting; addition/comparison rounding at the larger operand's DIGITS place.

## How to run things

Environment used in this session (the ooRexx install path is in the scratchpad file `orpath`):
```
OR=$(cat /tmp/claude-0/-home-claude-oorexx/*/scratchpad/orpath)
export OO_ROOT=$OR REXX_BIN=$OR/bin/rexx REXX_LIB=$OR/lib PATH=$OR/bin:$PATH LD_LIBRARY_PATH=$OR/lib REXX_PATH=$PWD
```
Regression at hand-off: all 60 scripts rc=0; compress 4/4, archive, json 284/284, crypto 8/8 SAME.
Regression (about 40 minutes on 2 CPUs): every `tests/test_*.sh` and `native/test_*.sh`; `tests/test_kernel_objects.sh`
needs `RX2CPP_KERNEL=<kernel build dir>`.

Profiling a native library: build normally, then
```
valgrind --tool=callgrind --callgrind-out-file=x.cg rexx prog.rex
callgrind_annotate x.cg | head -60
```
`RX2CPP_BIF_STATS=1` prints, at exit, every BIF / String method / CALL that went to the interpreter and how often.
