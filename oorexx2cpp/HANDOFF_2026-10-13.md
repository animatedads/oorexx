## rx2cpp compiles itself

```
native/build_self.sh /path/to/outdir          # builds outdir/librx2cppc.so, then checks the fixed point
RX2CPP_COMPILER_LIB=/path/to/outdir native/build.sh pkg.cls outdir lib    # generate with the compiled compiler
```

- `build_self.sh` combines the compiler's own packages (the `::requires` of `rx2cpp_native_library.rex`: 72 files,
  5,018 lines, 85 classes) into `outdir/rx2cppc.cls` and builds `librx2cppc.so` with the native lane.
- Fixed point (checked on every build): the native compiler and the interpreted compiler each compile that source;
  all four outputs (generated.cpp ~2 MB, .hpp, package glue, declaration) and the compiler's own output must be
  byte-identical, else the script fails. Identical C++ means a stage-2 compiler is the same compiler.
- Speed: compiling the compiler 55 s native vs 190 s interpreted. NotNotes nosql (16,301 lines): C++ generation
  about 4 minutes native; the interpreted compiler had not finished after 58 minutes.
- With `RX2CPP_COMPILER_LIB` set, `native/build.sh` runs `rx2cpp_native_library.rex` with its compiler packages
  replaced by `::requires 'rx2cppc' library`. The library must be rebuilt after any change to the rules/compiler.
- `RX2CPP_PROGRESS=1` prints per-phase / per-class timings of the generator to stderr.

## Known differences that remain

- A compiled routine called by the interpreter cannot know its call type: PARSE SOURCE there is a run-time error.
- The stream table of a compiled routine called by the interpreter is its own (the interpreted caller's is not
  reachable from native code); compiled-to-compiled calls share it, as interpreted.

- A run-time error inside compiled code shows `*-* Compiled routine "A".` in the traceback instead of the source line.
- Compiled `ADDRESS` commands do not raise ERROR / FAILURE for a trap yet; SIGNAL ON ANY does not raise NOVALUE.
- In a combined library all source files share one package, so a private class of one file is visible to the
  other files of the same library (the interpreter would hide it).
- `tests/test_extlib_repair_v028.sh` needs `RX2CPP_EXTLIB_ROOT` (external package, not present here).
